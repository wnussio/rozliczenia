ROZLICZENIA – INSTRUKCJA
========================

Link do aplikacji: https://wnussio.github.io/rozliczenia/


A. JEDNORAZOWA KONFIGURACJA BAZY (Firebase, darmowe, ok. 5 minut)
-----------------------------------------------------------------
Baza przechowuje paragony i synchronizuje je między telefonami.

1. Wejdź na https://console.firebase.google.com i zaloguj się kontem Google.
2. „Utwórz projekt” → nazwa: rozliczenia → Google Analytics możesz wyłączyć → Utwórz.
3. Menu po lewej: Kompilacja (Build) → Authentication → „Rozpocznij”
   → zakładka „Metoda logowania” → „Anonimowo” → Włącz → Zapisz.
4. Menu: Kompilacja → Firestore Database → „Utwórz bazę danych”
   → lokalizacja: eur3 (Europa) → tryb produkcyjny → Utwórz.
5. W Firestore otwórz zakładkę „Reguły”, usuń wszystko, wklej całą
   zawartość pliku firestore.rules z tego repozytorium → „Opublikuj”.
6. Ikona ⚙ (obok „Przegląd projektu”) → Ustawienia projektu → na dole
   „Twoje aplikacje” → ikona </> (Sieć) → nazwa: Rozliczenia →
   NIE zaznaczaj Firebase Hosting → Zarejestruj.
7. Skopiuj pokazany blok firebaseConfig (apiKey, authDomain, projectId…)
   i wklej te wartości do pliku app/firebase-config.js. Zapisz, wyślij na
   GitHub (albo poproś Claude'a, żeby to zrobił).

Dane z firebaseConfig nie są hasłem. Firebase zakłada, że są publiczne.
Dostęp chronią reguły z kroku 5 i tajny kod bazy, który jest w linku do dołączenia.


B. INSTALACJA NA TELEFONIE
--------------------------
Tak samo jak Farmaceuta: to aplikacja webowa (PWA), nic nie trzeba odblokowywać.

Android (Chrome): otwórz link → menu ⋮ → „Zainstaluj aplikację” / „Dodaj do ekranu głównego”.
iPhone (Safari): otwórz link → Udostępnij (kwadrat ze strzałką) → „Do ekranu początkowego” → Dodaj.


C. PIERWSZE URUCHOMIENIE
------------------------
1. Pierwszy telefon: „Utwórz wspólną bazę”.
2. Ustawienia → „Wyślij link” → wyślij go drugiej osobie (SMS, Messenger…).
3. Drugi telefon: otwórz link w Chrome / Safari (nie w Messengerze!) →
   „Dołącz” → potem zainstaluj aplikację jak w punkcie B.
   Jeśli aplikacja jest już zainstalowana: skopiuj link i wklej go w polu
   „Kod bazy” na ekranie startowym.
4. Od teraz oba telefony widzą te same paragony i to samo saldo.

Kto ma link, ma dostęp do rozliczeń. Nie publikuj go nigdzie.


D. SKANOWANIE PARAGONÓW
-----------------------
Skanowanie robi Claude (Anthropic) przez Twój klucz API:
1. https://console.anthropic.com → zaloguj się → Billing: doładuj np. 5 $.
2. API Keys → Create Key → skopiuj (zaczyna się od sk-ant-).
3. W aplikacji: Ustawienia → Skanowanie paragonów → wklej → „Zapisz klucz”.
Klucz zapisuje się tylko w tym telefonie. Jeśli druga osoba też ma skanować,
wpisuje klucz u siebie (może być ten sam). Jeden skan kosztuje kilka groszy.
Bez klucza wszystko działa, tylko pozycje wpisuje się ręcznie.


E. JAK LICZONE JEST SALDO
-------------------------
Przy każdej pozycji wybierasz, czyja jest:
- Wspólne → druga osoba oddaje płacącemu połowę,
- rzecz płacącego (np. Marcin płaci za swoje części do roweru) → nic do oddania,
- rzecz drugiej osoby (np. Monika kupuje Marcinowi coś do roweru) → oddaje całość,
- własne podziały (Ustawienia), np. „Dom 60/40”.
„+ Kwota” służy do wydatków bez paragonu (rachunek za prąd, pizza, bilety).
„Zapisz spłatę”, gdy oddacie sobie pieniądze. Saldo wtedy się zeruje.
